# Portfólio de páginas para profissionais da saúde

Página de vendas do Grupo G2F AI, com demonstrações conceituais para psicologia e nutrição.

- Página principal: `index.html`
- Demonstração de psicologia: `cases/marina/`
- Demonstração de nutrição: o cartão da Lívia aponta para [a página conceitual publicada](https://livia-azevedo-nutricao-conceito.grupog2f-ai.chatgpt.site/).
- Versão publicada: [g2f-presenca-digital-saude.grupog2f-ai.chatgpt.site](https://g2f-presenca-digital-saude.grupog2f-ai.chatgpt.site/)

O site é estático. Para publicar pelo GitHub Pages, selecione a branch `main` e a pasta `/ (root)` em **Settings → Pages**.
